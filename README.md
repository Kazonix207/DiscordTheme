# how to install ?
1.install project 
2.Go to the Vencord Themes section and click Upload Theme. Make sure you import the KazonixThemeDiscord.css file, not any other file.

# 🎨 Discord Theme
  Windows XP Theme
  Color Theme (orange) 

# ✨ Features
  😶‍🌫️Blur Theme
  🟧Border Theme orange
  ⬜Glow and lighting mesages
  ⬛Server list in 2 columns
  🟧Orange scroll bar
  ✅Compatible with BetterDiscord and Vencord
